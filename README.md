# Focus Flow

Focus Flow is a calm, browser based Pomodoro timer for turning a long to do list into one focused step at a time.

## Features

- 25 minute focus sessions, 5 minute short breaks, and 15 minute long breaks
- A circular timer with pause, reset, and skip controls
- A daily task list with completion and delete actions
- Daily focus minutes and completed session count
- Optional end of session sound
- Local storage, so tasks and today's progress stay in the browser
- Responsive layout and Turkish interface
- No build tools or dependencies required

## Run it

Open `index.html` in a modern browser. The Google Fonts import needs an internet connection; the app still works with system fonts when offline.

## Tech

HTML, CSS, and vanilla JavaScript. All data stays in the browser's local storage.
